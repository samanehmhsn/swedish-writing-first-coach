How it works

An editor, a conversation partner, and a memory for mistakes.

The core design choice was simple: ask the learner to try first. Only then provide corrections, explanations and reusable language. Every correction stays visible, so learning happens through comparison rather than silent rewriting.

Example coaching interactionFictional demonstration

A learner describes their work.

Jag också jobbar med min egna ide.

The learner produces a draft before seeing a model answer.

Only the incorrect spans change. Everything else stays in place.

Jag också jobbar jobbar också med min egna ide min egen idé.

An editor-style approach, not a wholesale rewrite.

Grammar in context: In a main clause, också normally follows the finite verb here. Egen agrees with singular idé.

I'd also like to …Jag skulle också vilja …
I'm working on my own idea …Jag jobbar med min egen idé …

Next step: write two original sentences using the patterns in another context.

System design

A repeatable instruction-based workflow.

The package combines SKILL.md with a curriculum, session template, fictional example and a blank learning log. The coach tracks vocabulary gaps, reusable phrases and recurring patterns only when an actual writable record is available.

Prototype status: This is an instruction-driven AI skill, not a deployed learning platform. This page is an illustrative static demo, not a live AI tutor. No private learner history is included.
